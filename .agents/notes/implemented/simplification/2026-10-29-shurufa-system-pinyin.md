# Agent Note: Shurufa 对齐系统拼音的输入边界

Status: implemented

## Problem

用户要求 Shurufa 只提供中文组字、神经网络排序、候选窗和语音。英文由系统 ABC 输入。原宿主仍有内部英文模式、应用规则与记忆，以及在激活、偏好刷新和客户端切换时请求系统选源的路径。仅隐藏控件或修改默认值无法阻止旧偏好重新开启这些行为。

## Decision

Shurufa 以系统输入源为唯一权威，所有主动选择入口均返回，不启用按需模式、不请求 `.Roman`，不恢复内部英文状态。`englishMode` 固定为 false，按应用的中英文规则与记忆不参与运行。现有偏好文档保持兼容，其他 edition 保留原行为。

当前控制器只接收自己的客户端模式报告；旧控制器不把旧 sender 报告转给当前控制器。有效中文模式报告仍可以同步中文方案，英文报告不进入内部英文模式。离开输入源时清除临时输入状态，不创建浮动工具栏。`mode_sync` 以 default 日志记录观察到的输入源及 `emitted=0`，不记录文本、按键或凭据。

Shurufa 不再处理 Shift/Control 轻点、Shift+空格、Control+Option+空格、Option+Shift+H，以及自定义中英文候选、标点、全半角、简繁切换和维护快捷键。只保留一个语音绑定；组字编辑与候选导航键保持独立。已移除的固定切换键交还应用，不取消或提交组字。偏好旧 true 不生效，原生录键与共享保存校验不再把这些入口当作占键者。

运行时副本关闭配对标点、字母/数字后的智能标点、重复标点转换和空格转换；保留基本中文标点。关闭 Shift+字母快捷模式、临时英文/日文、日期（含行内候选）、Unicode、快捷短语、Emoji/颜文字、超级简拼、计算、命令、提及、拆字、符号模式与混合候选。共享 Host API 在创建会话和应用偏好时统一约束副本，存储文档不增加选项。专用英文 API 返回当前视图，不能取消组字；配对标点 API 始终关闭。

网址/邮箱自动托管原先没有偏好开关，在 `www.` 或邮箱前缀上仍会进入英文组字。因此引擎内部增加 `local_url` 能力字段，默认 true，Shurufa 固定 false；入口、补全和显式模式进入共同遵守。此字段不进入设置页面。

Shurufa 不创建浮动工具栏，菜单不含英文输入或英文候选，菜单快捷键提示同步移除。方向键移动候选，数字和空格选词，中括号及减号/等号翻页，滚轮浏览固定可用；关闭以词定字及逗号/句号翻页，避免抢走中括号和基本标点。根据 [Apple 候选字窗口说明](https://support.apple.com/zh-cn/guide/chinese-input-method/cim12992/mac)，方向键、数字、空格、中括号、减号/等号与滚轮有文档依据；这里采用现有分页能力表达文档的“下一行/上一行”，实际系统手感仍待用户比较。

简繁输出、中文标点、全半角能力仍能在设置中更改，本次只移除它们的自定义切换快捷键。

## Historical audit

- [输入源恢复](../bug-fix/2026-10-21-macos-input-source-restore.md)：部分重叠。本篇取代其在 Shurufa 中保留主动选源的决定，其他 edition 的校准机制保持。
- [系统 Caps Lock](2026-10-29-shurufa-system-caps-lock.md)：部分重叠。继续让 macOS 负责 Caps 切换 ABC，不读实体 Caps 状态、不撤回锁定位。
- [单一语音快捷键](../feature/2026-10-28-shurufa-single-voice-shortcut.md)：部分重叠。保留单一语音绑定与触发方式；非语音的自管语言切换由本篇取代。
- 品牌、安装唯一宿主、语音持续会话、浮层预览及整理反馈笔记独立于本次中文组字边界，保留。

## Alternatives considered

仅修改默认值和隐藏设置能够减少改动，也能保留旧用户自行开启的能力。但这会留下不可见的语言切换与主动选源，违背用户要求，因此在实际运行入口限制 edition。

## Testing

`shurufa-system-source` 使用合成客户端、偏好和输入源，断言激活、偏好刷新、普通按键、客户端切换及直接调用选择函数时，选源调用数均为 0。测试也覆盖旧英文默认值、应用规则、显式英文设置以及旧 sender 报告。测试不注入系统键盘事件、不切换真实输入源。

`shurufa-system-shortcuts` 使用旧开关全开的合成偏好，覆盖双侧 Shift/Control、三组固定组合键、直接调用切换方法与组字保持。共享偏好保存/重载测试覆盖已释放的语音绑定。第一步原生全量 212/214，通过项之外只有既有 `shortcut` 和 `skin-preview` 失败；`shortcut-expanded-scroll` 本轮通过。第一步 quick 退出 1，25 条失败名称与交接基线相同。

## Consequences

Shurufa 不提供自管英文模式，用户通过 macOS 选择 ABC。系统 Caps→ABC 设置由用户管理。源码与合成测试不能证明微信问题已经解决；安装后需要用户在微信、TextEdit 或备忘录中手动复试，并对照持久日志。

设置页不显示内部输入模式、应用规则、已移除的切换键、智能/配对标点、混输、快捷模式和候选导航开关；导航固定可用，按键页只保留语音设置入口。简繁、中文标点、固定标点、全角输入控件保持可用。输入源声明也不再提供 `.Roman`，英文入口统一使用 macOS ABC。系统拼音的方向键边界、分页与实际换行的差别、标点细节及微信行为尚未在实际系统输入中核实，不能将产品目标写成已完成的一致性验收。
