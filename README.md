# Shurufa

> 一个输入法，它首先要能打字。

Shurufa 是我自己用的 macOS 中文输入法，结合了[水杉输入法](https://github.com/metasequoiaime/msime)和 [OpenLess](https://github.com/Open-Less/openless)：打字内核来自水杉，本地流式语音识别的起点来自 OpenLess，之后沿着我自己的日常使用习惯，把**中文候选排序链路**和**全链路本地语音听写/润色体系**做了一轮从底到顶的重构与打磨。

**这只是一个个人 fork 的项目，它只适合我自己的设备（目前只在 Apple Silicon Mac 上用）。**

## 为什么要 fork

水杉是一个很有野心的项目：六个平台、几十种快捷模式、云同步、插件、皮肤，要照顾各种各样的用户。而我对输入法的要求朴素得多：先在我这台 Mac 上把字打得稳、打得准，再加上一套足够聪明、低延迟、纯本地可控的语音输入。所以我把它 fork 下来，关掉用不到的，把最在乎的两件事往深里做。

## 我的一点看法

在 AI 时代，一个仓库要去适配所有人机器上的各种边缘情况，是非常费劲的：每多一个平台、一个选项、一种用法，就多一份要验证、要维护的组合，最后谁都照顾不周全。反过来，改代码的成本已经低了很多，在别人的软件基础上改出一个只给自己用的版本，往往比等上游照顾到你的情况快得多。

所以我鼓励大家：遇到好用的开源软件，fork 下来，针对自己的机器和习惯去改造它。

## 这个仓库的约定

- **不接 PR。** 一切以我自己用得爽为准。
- **没有支持多平台的打算。** 目前只在 Apple Silicon Mac 上自用；原先从水杉继承的其他五个平台、Tauri/React 外壳、脚本插件与非拼音语种代码均已物理移除。
- **不跟随上游。** 分叉点是 tag `fork-point/msime-2026-10-27`，之后的上游提交不合并。

## 相比上游做了哪些改进

### 一、瘦身与系统边界

- **纯 macOS 单产品与原生宿主**：仓库只保留 8 个核心 Rust crate、`platforms/macos` 原生 `Shurufa.app` 宿主与 `ShurufaNeuralService`，物理移除其余五个平台、Tauri/React 外壳、脚本插件、非拼音语种方案、8 套全拼辅助码表、包内 4.5 MB / 25 MB 旧 `safetensors` 模型以及 Sparkle 自动更新，强制关闭使用统计和云联想。
- **系统输入源作为唯一权威**：去掉输入法内部的中英文切换状态与中英角标，英文直接交给系统 ABC，`Caps Lock` 原样交还系统。
- **输入能力白名单聚焦高频刚需**：仅保留全拼 + 双拼、OpenCC 简繁转换、基本中文标点与全半角、全拼/双拼 `Tab` 笔画（`h/s/p/n/z/d/x`）与偏旁部件筛选、英文单词自动补全、精选内联 Emoji 投影、小写 `v` 数字与算式、候选第 1–5 位固定排位、个人学习与自造词闭环及本地/云端语音；保留单一语音快捷键，去掉多套冲突热键。
- **固定本机签名身份**：使用登录钥匙串里自动生成的自签名证书 `Shurufa Local Signing` 签名，重编重装后麦克风、辅助功能、输入监控授权不丢失。
- **单一 `config.json` 与零拷贝 `ShurufaViewSnapshot`**：废除历史双进程遗留的 `NSUserDefaults + options.json` 双存储合并层，全部设置收敛至 `~/Library/Application Support/Shurufa/config.json`（首次启动幂等迁移旧偏好）；按键与翻页热路径通过只读 C 结构体 `ShurufaViewSnapshot` 零拷贝跨层传递，移除宿主侧 `_adaptiveCandidates` 影子分页状态。

### 二、中文打字引擎：更准、更稳、不乱跳

- **三段单向候选管线（`CursorSnapshot → RecallPool → UnifiedScorer → PurePresenter`）**：
  - 组字在焦点会话处原子绑定不可变 `CursorSnapshot`（含左右上下文与段内暂存前缀 `locked_prefix`，退格可反悔拆回拼音并自然推进 `Qwen3-0.6B` KV-Cache）。
  - `RecallPool` 只负责多源召回并产出带 64 位稳定 `CandidateId` 的结构化证据，严禁在召回阶段计算展示下标；`UnifiedScorer` 维护全仓唯一三参数对数线性目标函数；无状态纯函数 `PurePresenter` 一次性完成第 1–5 位固定排位与置顶 L4 席位锁定、首页纠错限流、内联 Emoji 锚定、英文补全（首页上限 3 席）与单字排座，所有操作经稳定 `CandidateId` 寻址。
- **Shurufa v2 统一概率词格与混淆网络（Tier 0）**：
  - 废除旧词格 `+47.63 nat` 人工断崖，**清空 356 条静态动宾离合词硬编码表**，将单字、多字词与万象 LTS `.gram`（修复 `LOG10_E` 错误衰减并重构为零分配查表）统一映射到同一自然对数概率空间。
  - 按句长自适应调度束宽（`56/40/32`、`terminal_beam = 224`）与中间列单字出边上限（`PER_PARENT_DEST_CAP = 8`），叠加多首词种子锚点、算子 C2 `[1, 1] -> [1, 1]` `.gram` 联合重解码、多样性保护上浮以及 3–4 字未测频占位整词经多词组合验证后的词网格原地升格（保留 `Database` 身份与可编辑性，同时继续后置未验证生僻占位词）；3+ 字整句首屏采用 `4+2` 读法布局与 `2+1+1` 成词首词优先多样性选拔，第 2–4 页直达 `24` 席前缀短词与常用单字（`MAX_RERANK_PATHS = 24` 上下文精选），同时过滤多音节零频扩展区古汉字与非主切分隔音单字，由 `PurePresenter` 统一一次性分配展示席位。
- **任意句长切分、简全混拼与物理键盘错拼信道**：
  - 任意句长 A* 零声母隔音切分 + 长句边界词法剪枝，解决长句漏切与耗时膨胀。
  - 简全混拼与 4+ 音节纯简拼走统一词网格解码；高频简拼与整串纠错按统一物理信道概率公平竞争，不再被数百条单字纠错淹没。
  - 统一建模 QWERTY 物理邻键、跨音节换位、缺后鼻音 `g`、跨音节 `-n+n-` / `-ng+g-` 同辅音吞音恢复（如 `chunuanhuakai -> 春暖花开`、`changjiangungun -> 长江滚滚`、`zhinengongju -> 智能工具`）、句尾 `*gn -> *n` 竞争（如 `mohuyign -> 模糊音`）与两字母非法尾恢复，去掉候选窗里重复的纠错回显。
- **进程外 Metal 两阶段端侧神经解码与两阶段状态机（Tier 1）**：
  - 将 `llama.cpp`（Metal）封装在包内独立助手进程 `ShurufaNeuralService` 与 `libshurufa_neural.dylib` 中；子进程生命周期管理、私有 UDS 二进制帧通信、`50 ms` 空闲预热防抖、热态快敲空格有界等待（`55 ms`）以及两阶段展示状态机全部收拢在纯 Rust `crates/input-runtime`，物理删除 ObjC++ `ShurufaNeuralClient`。服务异常时零掉键无缝降级回 Tier 0 并指数退避自愈，空闲 10 分钟或系统内存压力时自动卸载释放内存。
  - 自动发现本地纯预训练基座模型 **`Qwen3-0.6B-Base-Q4_K_M.gguf`（378 MB）**；读取光标前至多 **512 字完整上文**及右文前瞻（通过 `IMKTextInput` 与辅助功能采集，完整保留中文标点、空格、ASCII 与 Emoji，密码框严格禁用）做 KV-Cache 增量预热。
  - `ShurufaNeuralEngine` 收口为统一双边界条件对数概率算子（汉字与空格/标点非汉字全边界左 Token Healing + 右单字前缀边际化 + 句中右侧前瞻 + 无右文时多字候选 `，/。/？/！/\n` 右边界句读闭合校准，消除开放前缀虚高、英文后接空格单字 BPE 坍塌并协同占位长词句内末词 `.gram` 衔接）：单音节上文场景放行前 `24` 实证单字（当同音存在 `weight >= 100` 现代读音时拦住 `weight <= 1` 幻影异读单字反超）、多音节扫描前 `128` 基础候选对齐等跨度后缀（含 3+ 音节满池时向尾槽抢救至多 `2` 条后置未纠错精确词典整词，并与 `stat_from_lattice` 升格占位词按词网格桶独立归一）并执行共享 KV 批量打分与 `2+1+1` 首词多样性融合；高惊奇度难句按需触发局部窗口受限束搜索救回词典 OOV 整句；纯 Rust 运行时执行 `Provisional → Presented` 状态机（主线程 `<3 ms` 非阻塞，配 `~70 ms` 防闪微窗口；候选面板一经绘出即硬锁槽 0 绝不跳动，迟到神经回包仅重排槽 `1..`）。本地未放 GGUF 模型时自动无损回退至 Tier 0（统一概率词格 + 万象 `.gram`）。
- **更克制的防劫持个人词频学习与自造词闭环**：
  - 独立追加式个人学习叠加层（永不改写主词库静态权重），采用以榜首权重为锚的 **30 天半衰期贝叶斯排序** 与竞争多音节键空格确认，跨补全词夹层生效；统一由单一 `ProviderRegistry` 全拼词库引擎写入/失效缓存，消除跨实例缓存脑裂，并在逐字自组新词及 `Qwen3-0.6B` 受限束搜索上屏（含 `CommitCandidate`）时同步写入个人叠加层事件——高频核心词维持 1.8 次明确选择防劫持门槛，静态首位为低频词（权重 `< 500`）时新造词在同会话二次输入立即可召回至首槽。
  - **前台应用 `AppScope` 粗粒度场景隔离**：按前台客户端 `bundleIdentifier` 在内存中映射为 `general` / `im_chat` / `code_ide` / `docs_writing` / `browser_search` 五类场景桶（绝不落盘原始应用标识，密码框与隐私会话强制复位 `general`），同场景事件 `1.0` 计权、跨场景 `0.5` 计权，避免编程术语与聊天习惯相互劫持。
  - 单字键未置顶/固定永不劫持第 1 槽，交由语境同音（含单字与多字语境消歧及万象 `.gram` 跨界搭配）与引擎层统一手动置顶/固定排位接管。
  - **5 秒内紧接退格删光即时回滚**：选错词立刻按 Backspace 删光时确定性撤销该条选择并写入 **24 小时半衰期负反馈**，同时将个人增益严格钳位在 `[-1.5, +1.5]` nats 注入统一融合打分。
- **顺手的日常打字增强**：
  - **轻量 `Tab` 笔画与偏旁部件筛选**：全拼与双拼组字时按 `Tab`（预编辑显示 `｜`），可输入 `h/s/p/n/z/d/x`（横竖撇点折、点与任意单笔通配，依托随包 `msime-stroke.db`）或常见部件首字母/全拼/俗称（依托内置 `chaizi` 表）快速定位首字或含该首字词条，激活期间自动挂起 Tier 1 神经重排与内联 Emoji 投影以免打乱筛选窗口。
  - **精选内联 Emoji 投影**：重排后按精选映射表与独立本地 MRU 自动给出对应 Emoji，不打乱正文候选序。
  - **中文组字夹带离线英文与免切换句内同轨混输**：内置 `162` 条现代开发者与品牌标准大小写词表叠加层（如 `ChatGPT`/`macOS`/`GitHub`/`DeepSeek`/`PyTorch`/`MLX`/`PR`），支持 3～4 字母不可拆前缀、5 字母以上前缀、`Shift+字母` 大写起手英文补全，以及全拼整段不可全拼切分时的免切换句内中英同轨混输（至多 2 个英文槽位，如 `woshiyongmacos -> 我使用macOS`、`bangworeviewzhegepr -> 帮我review这个PR`），回车原样上屏，日常夹带英文无需来回切 ABC。
  - **小写 `v` 快捷工具**：全拼里打小写 `v` 接算式、数字或日期（如 `v1+2*3`、`v123`、`v2026.11.4`），`v` 后直接接字母仍按正常拼音处理。
  - **搜狗细胞词库与 Rime 词典导入**：原生词库窗口支持整份分批导入 `.scel`（含 `DCS`/`ECS` 布局）与 Rime `.dict.yaml` / `.yaml` / `.yml`（自动识别 YAML 头并跨批保持格式），无权重词表按同音键既有词频动态标定，不再固定高权空降压过常用词。
  - **非激活候选右键菜单（第 1–5 位固定排位 / 置顶 / 删词）**：支持「置顶到第 1 位」、「固定排位 → 第 1–5 位 / 取消固定」与「删除/屏蔽词条」；固定排位写回 `fixed_candidate_positions` 并与手动置顶双向同步、作为 L4 硬约束全程穿透 `UnifiedScorer` / `SlotAllocator` / `PurePresenter` 且绕行云/AI/神经融合作业，同时不抢走浏览器或编辑器焦点。

### 三、全链路本地语音输入：从录音前端到自动学词

语音链路按「音频前处理 → 本地流式 ASR → 共享确定性后处理 → 上下文感知与本地/云端大模型润色 → 事后改错自动学词」分层搭建，整条链路支持**完全离线闭环运行**：

- **快捷键、交互与听感**：
  - 单一自定义快捷键同时支持「按住说话」和「轻按切换」，IMK 与系统事件双层严格校验左右修饰键（左 Option 不会误触右 Option 快捷键），系统层吞键不误触前台应用动作；录音期间普通按键不打断；上一条仍在识别/润色时再按快捷键会在浮层明确提示「按 Esc 可取消」。
  - 跨窗口录音时最终文本只投递一次；上屏前校验前台应用一致性与聚焦元素可编辑性，焦点落到桌面/按钮/空白网页等不可输入区域时绝不静默丢字，而是自动复制并弹出不抢焦点的毛玻璃「结果已保留 · 一键复制」预览卡片；`ctrl_v` 临时粘贴路径自动备份并在 220 ms 后无损恢复用户原剪贴板。
  - 录音浮层双态区分**已定稿**与**实时草稿**文字；干脆利落的 **300ms 镜像双音**开始/结束提示音（取代早期拖尾双响）。
- **音频前处理、设备闪断无缝迁移与全程 VAD 流式识别**：
  - 单次重采样同时供给识别和加密存档；16 kHz 单声道前端内置 80 Hz 二阶 Butterworth 高通滤波、噪声门控温和 AGC、软限幅与纯静音误触静默拦截。
  - **麦克风闪断与假连接自动无缝迁移**：首选外设拔出时起录自动回退系统默认麦；录音中途监听 `AVAudioEngine` 配置变更、CoreAudio 输入设备变化与 0.6 s 采集卡死看门狗，自动冲刷并无缝重建重采样器（兼容跨采样率/声道数如蓝牙 16 kHz → 内置麦 48 kHz），不中断同一条录音存档与流式识别；若所有麦克风彻底断开，自动抢救并提交已录语音而不丢弃。
  - **识别失败/超时原地一键重试**：失败或超时且已留存音频时，弹出不抢焦点的恢复卡片，可直接从本机加密存档取回 16 kHz PCM 原地重跑完整识别与润色链路并上屏/复制，也可一键跳至听写历史。
  - 本地流式识别 `TextStream`（`Qwen3-ASR-1.7B` + MLX）升级全程 Silero VAD 状态机，支持 256 ms preroll、句中长停顿跳过与长口述安全软切段（防 >30s 漂移截断），并按物理内存分级空闲回收与系统内存压力释放。
- **无网络确定性后处理引擎（Rust 共享层）**：
  - 即使关闭大模型润色、或润色超时/失败自动降级时，仍然输出整洁文本：保留代码缩进的空白规整、块边界单字结巴与句尾语气词清理、纯语气词/短静音幻觉/复读循环静默拦截、口述符号合并（如「某某杠某某」「横杠」「斜杠」「下划线」「点」合并为 `-`/`/`/`_`/`.`）、双边界保守 ITN、中英盘古之白、内置技术词大小写纠正、沿用引擎简繁规则。
- **深度上下文感知与选区口头改写**：
  - 录音启动瞬间在 ≤25 ms 预算内同步采集前台应用分类、窗口标题、浏览器域名、光标**前后双向上下文**与当前选区，并为 Chrome / Electron 应用安全唤醒 `AXEnhancedUserInterface`。
  - 同时在后台串行队列异步抓取当前聚焦窗口的**可见屏幕文本**（≤220 ms 预算，零阻塞主线程；对微信、Sublime、Google Docs、腾讯文档 `docs.qq.com/doc/` & `/sheet/` 设防卡死 AX 黑名单）。
  - 选中文本后可直接口头下达改写或翻译指令，经两层意图守卫识别后直接替换选区；密码框与安全输入框实施硬隔离（剥离全部上下文、可见屏、选区与词表，且阻断所有非本机回环润色端点）。
- **本机托管大模型润色 + 外部兼容**：
  - 支持 Shurufa 自动托管本机 `llama-server`（仅监听 `127.0.0.1`、内存态随机 256-bit API Key、录音开始即异步预热、固定字节前缀提示词命中 KV cache、按内存分级上下文与崩溃限频重启），也支持本机 `Ollama` 与外部 OpenAI 兼容接口（自动补全 `/v1/chat/completions`，可从 OpenLess 一键导入配置）。
  - 超过 7.5 秒给出慢响应提示；输出经过 `<think>` 剥离、助手元回复/异常膨胀塌缩/繁体漂移拦截，任何异常无损回退到确定性后处理结果。
- **15 秒事后改错自动学词与个人语音词表**：
  - 语音上屏后开启 15 秒观察窗，手动修改误识别的专有名词并按回车发送、清空或切走焦点时，自动做精准词边界差分提取（自动过滤清空发送、整句重写与纯中文单字噪音）并原子写入 `voice-vocabulary.json`。
  - 学到新词后在屏幕右上角弹出**不抢焦点的毛玻璃气泡**（显示 `已将「XXX」加入语音词库`，支持一键「撤销」精确恢复，悬停暂停 4.8 秒自动淡出）。
  - 语音设置页内置「个人语音词表」管理卡片，支持查看来源（手动 / 自动学习）、快捷增删并实时联动；词表与个人拼音/英文词库聚合后，按字面与拼音近似度筛选 Top-K 注入后处理与润色。
- **本机加密听写历史与离线评测**：
  - 每次录音用登录钥匙串自动生成的本地密钥加密存档，记录原始文本、最终文本、各阶段耗时、场景分类与降级/静默原因，设置页可查看历史与设置保留期限；配套 `voice_eval` 支持对 TextStream 与润色链路做离线基准评测。

完整的时间线与细节演进见[变更记录](docs/CHANGELOG.md)。

## 自己构建

只在我的环境里验证过：Apple Silicon、Command Line Tools 的 MacOSX26.5 SDK、Rust、Homebrew（CMake、Ninja、python@3.14、uv、`llama.cpp`——同时提供端侧神经解码所需的 `libllama` 与可选的本机托管润色 `llama-server`）。分层设计与本地门禁细节见[架构说明](docs/ARCHITECTURE.md)。

```sh
bash platforms/macos/build-shurufa.sh            # 构建 target/macos-isolated/Shurufa.app（含 ShurufaNeuralService）
bash platforms/macos/scripts/install-shurufa.sh  # 安装到 ~/Library/Input Methods/Shurufa.app
bash scripts/verify-local.sh                     # 运行笔记校验、契约检查、Rust 单测/Clippy 与全量 macOS CTest
```

构建时会按 `resources/editions/shurufa.lock.json` 拉取并校验核心词库，并准备轻量笔画词库 `msime-stroke.db`（不再拉取旧 25 MB `safetensors` 模型）；首次安装本地缺万象语法模型时会自动下载 `wanxiang-lts-zh-hans.gram`（约 373 MB）；将端侧神经语言模型 `Qwen3-0.6B-Base-Q4_K_M.gguf`（约 378 MB）放入 `~/Library/Application Support/Shurufa/resource-packs/neural-lm/` 后自动启用两阶段 Metal 神经解码（缺模型时自动无损降级回 Tier 0 统一概率词格与万象 `.gram`）；本地流式语音的运行环境与模型在设置窗口里按需用 `uv` 安装。构建按登录钥匙串里的本机自签名证书「Shurufa Local Signing」签名，没有时脚本会自己建一张。换到你的机器上大概率要改点什么，这正是上面说的：fork 下来，按你自己的来。
